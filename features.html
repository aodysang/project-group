ระบบและคุณสมบัติของ DYSHIRO

DYSHIRO คือแพลตฟอร์มแฟชั่นออนไลน์แนวมินิมอล ที่ผสานเว็บไซต์และแอปพลิเคชันเข้าด้วยกัน เพื่อให้ผู้ใช้เลือกซื้อและบริหารจัดการสินค้าได้อย่างสะดวก รวดเร็ว และสวยงามในทุกอุปกรณ์

System Overview

ระบบ DYSHIRO แบ่งออกเป็น 2 ส่วนหลัก ได้แก่ Web Application สำหรับการซื้อ-ขายสินค้า และ Mobile Application สำหรับลูกค้าและสมาชิก โดยใช้ฐานข้อมูลกลางที่เชื่อมโยงแบบเรียลไทม์

💻
Web Platform

เว็บไซต์หลักออกแบบให้ใช้งานง่าย รองรับทุกขนาดหน้าจอด้วย Bootstrap 5 และ Responsive Layout

📱
Mobile Application

แอปมือถือช่วยให้ลูกค้าดูสินค้า ลองสวมเสื้อ (AR Try-on) และรับการแจ้งเตือนโปรโมชั่นได้ทันที

Web System Features

🛒
Product Catalog

แสดงสินค้าเสื้อยืดพร้อมภาพ รายละเอียด ขนาด และราคา

💳
Order & Payment

รองรับตะกร้าสินค้าและการชำระเงินออนไลน์ผ่าน QR หรือบัตรเครดิต

📦
Delivery Tracking

ตรวจสอบการจัดส่งสินค้าและสต็อกแบบเรียลไทม์ผ่านหน้าเว็บ

Mobile Application Features

Virtual Try-On

ทดลองสวมเสื้อเสมือนจริงก่อนตัดสินใจซื้อผ่านกล้องมือถือ

🔔
Smart Notification

แจ้งเตือนโปรโมชั่นและสินค้าใหม่แบบเรียลไทม์

👤
Member System

ระบบสมาชิกสะสมแต้ม ดูประวัติการสั่งซื้อ และรับสิทธิพิเศษ
